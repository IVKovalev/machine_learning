# Machine Learning

**EN** · [RU](#машинное-обучение)

A collection of machine learning projects on classification and regression tasks. Each project is a Jupyter notebook covering the full workflow: data exploration, preprocessing, feature engineering, and training and comparing several models. Every folder has its own README with a short description of the project and its results.

| # | Project | Task | Description |
|---|---------|------|-------------|
| 1 | [Musical Preferences](1_Musical%20Preferences) | Classification | Predicting whether a user will like a song from their listening history (Kaggle competition). Focus on processing categorical data and feature engineering. |
| 2 | [Avocado Price Prediction](2_Avocado%20Price%20Prediction) | Regression | Predicting the average avocado price from sales volumes, type, region and season. |
| 3 | [Heart Disease Classification](3_Heart%20Disease%20Classification) | Classification | Predicting heart disease from patients' clinical data. |
| 4 | [Pulsar Stars Classification](4_Pulsar%20Stars%20Classification) | Classification | Separating pulsar signals from noise in HTRU2 radio survey data. |

**Stack:** Python, pandas, NumPy, scikit-learn, CatBoost, Keras, seaborn, matplotlib, plotly.

## Машинное обучение

[EN](#machine-learning) · **RU**

Подборка проектов по машинному обучению на задачи классификации и регрессии. Каждый проект - это Jupyter-ноутбук с полным циклом работы: исследование данных, предобработка, feature engineering, обучение и сравнение нескольких моделей. В каждой папке есть свой README с кратким описанием проекта и результатов.

| # | Проект | Задача | Описание |
|---|--------|--------|----------|
| 1 | [Musical Preferences](1_Musical%20Preferences) | Классификация | Прогноз, понравится ли пользователю песня, по истории прослушиваний (соревнование Kaggle). Акцент на обработке категориальных данных и feature engineering. |
| 2 | [Avocado Price Prediction](2_Avocado%20Price%20Prediction) | Регрессия | Прогноз средней цены авокадо по объёмам продаж, типу, региону и сезону. |
| 3 | [Heart Disease Classification](3_Heart%20Disease%20Classification) | Классификация | Прогноз заболевания сердца по клиническим данным пациентов. |
| 4 | [Pulsar Stars Classification](4_Pulsar%20Stars%20Classification) | Классификация | Отделение сигналов пульсаров от шума в данных радиообзора HTRU2. |

**Стек:** Python, pandas, NumPy, scikit-learn, CatBoost, Keras, seaborn, matplotlib, plotly.
